## 三网优化到底是什么，为什么便宜档带宽都这么小

国内三家运营商各有一条自建的高端国际线路：电信的 CN2 GIA（AS4809）、联通的 CUII / AS9929、移动的 CMIN2（AS58807）。普通国际线路走的是 163、4837 这类公共出口，高峰期拥堵、绕路、丢包是常态。

只优化电信一条线的套餐，哪怕去程回程都是 CN2 GIA，联通和移动用户走的仍然是普通线路，晚高峰该卡还是卡。三网优化的意思是三家各走各的高端线路，谁也不将就。这三条线路的带宽成本摆在那里，所以同配置下三网优化套餐总比普通线路贵一截。

带宽反过来就成了压缩成本的第一刀。LightLayer 把新加坡档压到 10Mbps、把圣何塞档做成 1Gbps，差价只有 $1.45，这 $1.45 买的其实就是那 100 倍带宽。香港独服的带宽选项更直白：10Mbps 优化、15Mbps 普通回国、20Mbps 国际，三档摆在明面上让你选。

## 10Mbps 够不够用，$3.5 和 $4.95 差在哪

10Mbps 大约等于每秒 1.25MB 的下载速度。单人 SSH 管理、跑轻量代理、请求量不大的 API 中转，这个带宽不会成为瓶颈。一个纯文字的静态小站也扛得住。

不够用的场景也很明确：多人同时在线看视频、图片多的 WordPress、跨境直播推流、需要下载大文件的任务。这些场景下 10Mbps 会立刻变成天花板，而且新加坡那款是合理使用不限流量，跑满带宽照样会被限速或警告。

1G 内存是两档共同的上限。跑 WordPress 会比较吃力，建站建议至少 2G 内存起步，这一条对 $3.5 和 $4.95 都适用。把这两档当成建站主力，配置是不够的。

圣何塞那档多花 $1.45，换来 1Gbps 优化带宽和每月 1TB 流量，用途一下子宽了很多：可以带几个人的小团队用、可以挂图稍多的站点、可以跑需要突发带宽的任务。差价这么小的情况下，除非你的预算就是死守 $3.5，否则没有理由选新加坡。

## 哪些人不用买三网优化

三种情况可以省下这笔钱。

白天用、晚上不用，或者主要跑定时任务、备份、爬虫这类不在乎延迟的活，普通国际线路完全够。RackNerd 那类 $21.99/年 的方案流量给得更多，官方介绍里自己也写了网络质量相对不够好，用途对得上的话就没必要为优化线路付费。

要正经建站、访客不算少，1G 内存的两档都不合适。省下的钱会在后面以卡顿和调优时间的形式还回去，直接往上选 2G 内存的配置更省事。

需要大带宽同时又要求低延迟，只有圣何塞 1Gbps 那档符合，新加坡的 10Mbps 不用考虑。
